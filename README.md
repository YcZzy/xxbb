# i播播了么（本地恢复版）

这是从微信小程序编译产物恢复并重新整合的原生小程序项目。

## 本地运行

1. 打开微信开发者工具。
2. 选择“导入项目”。
3. 项目目录选择当前文件夹。
4. 当前 `project.config.json` 使用 `touristappid`，可用于本地编译和界面调试。
5. 如需真实微信登录、订阅消息或支付，请把 `project.config.json` 中的 `appid` 替换为原小程序 AppID。

项目未使用 npm，不需要执行依赖安装或构建命令。

## 已恢复范围

- 主包：状态、爱播守候、星光档案、星光早报、帮助、官方入口。
- 分包：打 Call、在线人数档案。
- 组件、静态图片、页面脚本、WXML 和 WXSS。

“星光卡包”和“i币明细”已按要求移除，对应界面入口也不再展示。

## 后端说明

该项目未使用微信云开发 SDK，也没有调用 `wx.cloud`。前端通过 `wx.request` 连接独立后端：

```text
https://jk.maoqiuqiu.xin
```

认证流程为：

```text
wx.login() -> POST /api/v1/wechat/login -> Bearer Token -> 业务 API
```

客户端会把登录令牌保存在 `miniappApiSession` 本地存储中。接口封装位于 `services/api.js`，环境配置位于 `config/env.js`。

前端代码可以用于还原接口路径、请求方法、字段和主要业务流程，但当前目录不包含后端源码，无法仅凭该项目确认服务端使用的编程语言、数据库、任务队列或部署脚本。
